# TSEK frontend

React + Vite starter for TSEK. See the repository README for setup and Vercel deployment instructions.

- `npm install`: install dependencies
- `npm run dev`: start the local development server
- `npm run lint`: check source code
- `npm run build`: build to `dist/`
- `npm run preview`: preview the production build locally

Start editing in `src/App.jsx`. This starter does not yet upload or analyze documents.
